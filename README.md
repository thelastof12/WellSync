# Holistic Health Hub

WEBSITE DEVELOPMENT PROMPT — COMPREHENSIVE HEALTH & WELLNESS SYSTEM

Build a complete, modern, responsive Health & Wellness Management Web Application based on the provided academic mini-project proposal and Chapters 2 and 3.

The project is a comprehensive health and wellness system designed to solve the problem of fragmented health data by bringing Physical Activity, Nutrition, Mental Well-being, Sleep, and Habits into one unified platform.

The application must not feel like a generic fitness website. It should feel like a serious, polished academic final-year software project / real-world digital health platform, with a clean, modern, professional interface and meaningful data visualization.

1. PROJECT PURPOSE

The system should help users gain a holistic understanding of their health by allowing them to:

Track physical activity

Track nutrition

Track mental well-being

Track sleep

Track healthy habits

Set personal health goals

Monitor progress

View health trends

Understand relationships between different health domains

Receive personalized AI-powered health insights

Generate health reports

Manage their health profile and privacy

Eventually synchronize data with wearable devices and health platforms

The central idea is:

"One platform. Your complete health picture."

The system should demonstrate how different health dimensions interact rather than showing isolated metrics.

For example:

Sleep quality vs mood

Physical activity vs mood

Nutrition vs energy

Stress vs recovery

Habit consistency vs overall progress

The project proposal identifies fragmented health data, lack of cross-domain analysis, limited personalization, poor habit tracking, and poor user experience as major problems. The website should visibly address these problems.
